# 🌍 Pearls AQI Predictor

## Project Overview

Pearls AQI Predictor is an end-to-end Machine Learning project that predicts Air Quality Index (AQI) using pollutant data. The project includes data preprocessing, exploratory data analysis, model training, a Streamlit dashboard, and a Flask API for predictions.

---

## Features

- Data Collection
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Random Forest Regression
- Model Evaluation
- Streamlit Dashboard
- Flask REST API

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Flask
- Joblib

---

## Machine Learning Model

Random Forest Regressor

Evaluation Metrics:

- MAE
- RMSE
- R² Score
